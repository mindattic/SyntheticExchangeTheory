# Research notes

These are the working notes from the October 2026 citation-verification and source-expansion passes. Each file records, for every source, its full reference, the level at which it was verified (full text, abstract or publisher page, or record only), what it actually establishes, and how the dissertation uses it. Each ends with "Corrections to the draft" and "Synthesis notes".
